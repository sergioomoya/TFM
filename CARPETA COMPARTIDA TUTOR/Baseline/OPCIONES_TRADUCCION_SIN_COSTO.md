# Opciones de Traducción sin Costo

## OpenAI API - Tiene Costo

Sí, la API de OpenAI tiene costos asociados:
- **GPT-4o-mini**: ~$0.15 por millón de tokens de entrada, ~$0.60 por millón de tokens de salida
- **GPT-4**: Más costoso, ~$5-30 por millón de tokens dependiendo del modelo

Para traducir 5 cuadernos grandes, podría costar varios dólares.
